# lilac echoes

基于AI的心理疗愈与生成式公共艺术平台

### 主页

1. 在主页上用美工表示全校的心情

2. 几种心情分别对应不同元素，并且可以融合

3. TODO

### 地图拍照

1. 在地图选点，可以拍照+文字来写信笺

2. 随机看最新的几条分享

### 聊天

1. 每日新的AI

2. 一个长期的，对用户更加了解的AI

3. 这两个AI会总结当前用户的心理状况，和个人总结

4. 用户可以自主决定是否公开

##### AI功能

1. 推荐恢复心情/维持心情的活动

2. roll今日美食

3. 推荐校内活动地点

### 登录

简单注册+登录+简单的头像
